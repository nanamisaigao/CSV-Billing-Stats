# CSV账单统计

一个用 Python 标准库实现的 CSV 账单分析工具：按月份汇总各分类花费，计算占比，并跳过异常行。

## 基础功能

- 读取 CSV 账单文件，按**月份**汇总总花费
- 按**类别**统计金额及占比
- 遇到异常行**跳过并计数**，不中断整体分析
- 输出月度明细 + 总计 + 跳过行数

## 环境要求

- **Python 3.13+**
- **仅使用标准库**

## CSV格式说明

```csv
日期,类别,金额
2024-01-01,餐饮,35.5
2024-01-02,交通,12
2024-01-05,餐饮,48
```

## 运行方式

```bash
python analyzer.py
```
默认读取脚本同目录下的账单 CSV 文件，具体文件名以脚本内配置为准。

## 异常处理

```
以下情况会跳过该行并计数，不影响其他数据：
- 金额为空或非数字
- 缺列
- 空行（由 csv 模块自动跳过，不计入跳过数）
```

## 已知限制

- 行号偏移：跳过的行号基于数据列表序号，CSV 中有空行时会与真实行号偏移
- 未处理除零：没有覆盖“月份总额为 0”的除零情况
- 列名固定：要求 CSV 表头必须为 日期,类别,金额，列顺序变化会导致解析错误
