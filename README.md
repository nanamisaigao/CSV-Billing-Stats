# CSV账单统计

数据处理

## CSV格式说明

```csv
日期,类别,金额
2024-01-01,餐饮,35.5
```

## 运行方式

```
python analyzer.py
```

## 异常处理

```
以下情况会跳过该行并计数，不影响其他数据：
- 金额为空或非数字
- 缺列
- 空行（由 csv 模块自动跳过，不计入跳过数）
```

## 已知限制

- 跳过的行号基于数据列表序号，CSV 中有空行时会与真实行号偏移
- 没有覆盖“月份总额为 0”的除零情况

## 环境要求

Python 3.13+，仅用标准库。
